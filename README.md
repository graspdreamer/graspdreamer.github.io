# GraspDreamer

Anonymous supplementary website for **Fine Grained Grasp Generation**.

[Open the interactive website](https://graspdreamer.github.io/).

Browse 19 selected objects and 38 recorded grasp generations. Choose a recorded language
instruction, compare its finger configuration, and inspect the static grasp from
different camera angles using the interactive viewer and angle slider.

The site preserves the recorded prompts, generated poses, finger measurements,
and high-resolution views. Hand surfaces are subdivided for visualization only;
measurements use the original generated meshes. Raw meshes are not distributed.
